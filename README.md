# The Gathering Co.

Phase 1 marketing site for a Newcastle event hire business. Static-first Next.js, WhatsApp as the conversion path,
no database.

- `docs/SPEC.md`: the build brief, scope, pages, tokens and open items
- `docs/RUNBOOK.md`: commands, environment variables, deploy steps and every placeholder to replace
- `CLAUDE.md`: conventions every coding session inherits

```sh
pnpm install
cp .env.example .env.local
pnpm dev
```
